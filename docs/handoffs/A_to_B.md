## Known limitations

- Shelter positions use an approximate non-official GCJ-02 inverse; capacities are 2024 registry values, not independently confirmed current usable capacities.
- The polygon is not an official East District boundary.
- OSM was retrieved online through OSMnx; no fixed PBF snapshot was used. Future downloads can differ.
- Travel time is network distance plus straight-line snap access legs divided by the configured assumed walking speed; it is not observed travel time.
- Route example is generated but not manually checked.
- The A7 audit command must be run after each GIS rebuild to refresh reason counts and the release verdict.

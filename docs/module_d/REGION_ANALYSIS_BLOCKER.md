# 东区 / 小榄分析链路诊断

诊断日期：2026-11-24。验证对象是本机 Module D、C 和 B 实际进程；没有更改 A/B/C 正式代码。

## 结论

这是 C→B 的数据源配置链路不匹配，不是东区或小榄缺少 A v2 地理数据，也不是前端地图加载失败。

## 复现证据

| 地区 | A v2 / C 目录 | C Session | 提交能力评估 |
|---|---|---|---|
| 东区街道 `east_district` | 200；38,469 个需求节点、31 个场所、1,192,539 条 OD；`shelterplan_module_a_v2.0-demo__east_district` | 201，Session 和 data_version 均正确绑定东区 | C `FAILED`：`B_SCENARIO_INVALID`；`Requested data_version does not match an allowed Module A source` |
| 小榄镇 `xiaolan` | 200；60,406 个需求节点、31 个场所、1,872,586 条 OD；`shelterplan_module_a_v2.0-demo__xiaolan` | 201，Session 和 data_version 均正确绑定小榄 | C `FAILED`：同一 `B_SCENARIO_INVALID` 和版本拒绝原因 |

两次失败都在 B 的数据源/情景校验阶段结束，没有 `result_id`、Solver 状态或 Verifier 状态，因此不是求解性能问题。

当前 [module_b.yaml](../../configs/module_b.yaml) 固定 `source_config: configs/module_a_v2_b/shiqi.yaml`。B 的 [executor.py](../../backend/graph/executor.py) 只把当前配置版本和旧版 pilot 适配器视为可接受源；它不会按每个 C Session 的 region 自动选择其它配置。虽然 `configs/module_a_v2_b/east_district.yaml` 和 `xiaolan.yaml` 都存在，单个当前 B 进程仍只加载 Shiqi。

链路实际行为是：

```text
A v2 三地数据与 Manifest ──正常──> Module D 地图 / C 区域目录
                                      │
                                      └── C 创建正确地区 Session
                                            │ 传递对应 data_version
                                            ▼
                                      B 仅加载 Shiqi source_config
                                            └── 版本校验拒绝，未进入求解器
```

## 为什么之前看起来可展示的样例少

- 首页默认选择 Shiqi，首页指标和地图随当前地区切换；运行与证据页按当前地区 Session 展示真实执行记录。
- 前端没有伪造历史结果。东区和小榄的请求都被 B 拒绝，因此没有可展示的规划结果和证据。
- A v2 实际有三个地区：Shiqi 7,336 个需求节点 / 25 个场所 / 183,400 条 OD；东区 38,469 / 31 / 1,192,539；小榄 60,406 / 31 / 1,872,586。图层仍可查看，GIS 预览不等于 B 规划已经可运行。
- 前端首页现增加三地数据集卡片，可直接切换查看；B 版本不匹配时显示可读原因和所需配置，不再把接口原始英文错误当作普通失败提示。

## 解除阻塞所需的后端工作

推荐在 B 建立显式白名单式数据源注册表，通过 `region_id + data_version` 唯一匹配现有 `configs/module_a_v2_b/{region}.yaml`，并让源缓存按选中的配置隔离。必须拒绝未知地区、版本不匹配和任意路径，不能静默回退到 Shiqi。另一个可行部署方式是每个地区运行独立 B，再由 C 按 Session/地区选择对应 B 地址；当前单个 C `b_base_url` 配置没有这种动态路由。

这属于 B/C 集成行为改动，超出本轮前端审美与诊断范围；当前没有绕过校验，也没有伪造成功结果。

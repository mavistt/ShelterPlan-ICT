## 限制与解释

- A v2 数据全部标记为 `DEMO_ONLY` / `PASS_DEMO`；坐标、容量、开放状态未经过现场核验。WorldPop 是模型人口估算，步行可达图层不能解释成容量约束下已服务人口。
- 假设预算优化仅用于展示流程与求解器行为，不能当作真实工程预算或应急配置建议。
- 本轮没有接入付费 LLM；Rule/fallback 通过不等同于真实 LLM Agent 性能验证。
- GeoTIFF 未在浏览器渲染；A 图层读取由本地 Vite allowlist 中间件提供。生产部署需要部署等价的受限数据 API 和 `/api/c` 同源代理。
- 本地 Module C 没有认证，不应把 Vite 开发服务暴露到不可信网络。
- 已构建的 MapLibre、ECharts chunk 仍较大；生产演示前可以按页面拆分图表和地图模块。
